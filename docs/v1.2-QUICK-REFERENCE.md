## FAQ

**Q: Why is the price going up by ₹8,000 if these are "low-effort" features?**  
A: ₹8k covers 10 additional dev-days (₹800/day at competitive rate). Each feature, while simple, still requires full development cycle (backend, frontend, testing, admin UI). The discount is maintained at 27.27% — still 30% off estimation.

**Q: Can we add features without timeline extension?**  
A: Not recommended. 3.5-week crunch + 6 new features = high risk of bugs/corners cut. 4.5–5 weeks lets us maintain quality + testing. If time is critical, defer translator + GMB (cosmetic) and ship with 4 core features; still hit 4-week mark.

**Q: What about Phase 2?**  
A: v1.2 is **the** launch version. Phase 2 (coupon codes, live tracking, nested categories, etc.) comes after go-live. v1.2 additions are baseline; further requests require separate scope amendment.

**Q: Will reviews/reminders/EMI work well for gate automation products?**  
A: **Yes, perfectly.** Gate motors are considered purchases (high-value, research-intensive). Reviews help decision-making. EMI makes ₹25–50k products affordable. Reminders recover window-shoppers. These are proven e-commerce mechanics.

**Q: Can customers leave fake/negative reviews?**  
A: Admin approves all reviews before display. Negative reviews are OK (authenticity builds trust); spam is rejected. reCAPTCHA v3 blocks bots. Net result: mostly legitimate reviews.

**Q: Does translator work for all languages equally well?**  
A: Google Translate does well on product names, specs, prices. Marketing copy sometimes feels robotic. For v1.2, automated translation is sufficient. In Phase 2, you can hire a professional translator for critical pages.

**Q: Is reCAPTCHA v3 user-friendly?**  
A: Yes — **invisible to users**. No "I'm not a robot" clicks. Legitimate customers don't notice it. Bots + spam get silently rejected. Only users with very suspicious behavior might be challenged.

**Q: What about GDPR / email compliance for reminders?**  
A: Full compliance built in. Unsubscribe link in every email. Opt-out tracking in admin dashboard. Users can disable reminders per product. CAN-SPAM + GDPR aligned.
